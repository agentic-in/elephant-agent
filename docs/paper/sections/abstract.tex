Many agent systems now improve along three visible axes: executing tasks,
carrying context, and improving procedures. For personal AI, these are not the
final product position. The fourth level is agency-first: the system should help
the person keep judgment, evidence, questions, and growth while agents do more
work. Elephant Agent is a \emph{personal-model-first} architecture for this
fourth level of personal AI. It centers a Personal Model: a durable, grounded
understanding across four lenses: who the user is (\textit{Identity}), what surrounds them
(\textit{World}), what is alive right now (\textit{Pulse}), and what their path
has taught them (\textit{Journey}). This system treats memory as five cooperating layers rather than a transcript
archive or a vector store: Matriarch Core / Personal Model, Elephant State,
Episode / Loop / Step Trail, Contextual Recall, and Background Learning. Raw
Steps preserve what happened; contextual recall retrieves support from Steps
and Facts; proactive questions expose gaps, conflicts, stale Pulse, and useful
adaptations; background learning decides when evidence should change durable
claims. The system's self-evolution loop works as follows: curiosity identifies what
would improve future help, and reflect jobs turn lived evidence into governed
Personal Model updates. There is no free-form memory-note table or foreground
memory write surface. Durable understanding is written through governed
Personal Model tools and remains inspectable, correctable, and
source-provenanced. In this report, we describe the agency-first product position, Elephant Agent architecture, four-lens Personal Model
schema, proactive curiosity loop, local semantic recall path, background reflect
pipeline, dashboard inspection surfaces, and evaluation scenarios for wake
recovery, correction, no-match recall, and memory quality over time.
