# Elephant macOS Design Review

This is the working UX bar for the native Mac app. Each visual iteration should start by arguing against the current design before adding more UI.

## First-Impression Test

- The first screen should read as a native app, not a repackaged dashboard.
- The brand signal should be unmistakable within two seconds: Elephant logo, living memory orb, local-first language, and light glass environment.
- The app should feel calm and capable, with one playful accent at a time. Avoid mascot-heavy, marketing-heavy, or all-blue compositions.
- Product images should support context and evidence, not become generic hero photography.

## Current Direction

- Visual language: Living Glass, a light macOS material system with soft mosaic motion, radial signal glows, and thin glass cards.
- Brand personality: precise like OpenAI-style tools, warmer and younger through rounded SF typography, small colorful signals, and evidence-map motion.
- Information architecture: Home, Wake, You, Reflect, Jobs, Skills, Settings. Setup is an init flow, not a top-level tab.
- Daily workflow: Wake first, review questions, run Reflect, keep scheduled work visible.

## Critical Checks

- If a page can be mistaken for a website section, reduce hero copy and make the interaction more direct.
- If a card only reports data, add a next action or make it visually subordinate.
- If an image feels decorative, shrink it, crop it into a source/evidence object, or remove it.
- If every surface uses the same blue tint, rebalance with mint, coral, gold, or neutral glass.
- If onboarding feels like a form, add intent, progress, and a visible sense of profile formation.
